Setup

Getting set up

Do I use the Claude files or the ChatGPT files?

Whichever AI you already use. You don't need both. The four files ending in .zip are for Claude. The four files ending in -chatgpt.txt are for ChatGPT.

My Claude upload failed. What do I do?
  1. Make sure you picked a file ending in .zip, such as calm-weekly-scorecard.zip, not a .txt file.
  2. Upload the .zip exactly as it came. Don't open, unzip, or rename it first. On Windows these show as "Compressed (zipped) Folder," which is correct.
  3. Check that Code execution and file creation is turned on: go to Settings, then Capabilities. On some screens it's called "Create and edit files." Skills need this setting.
  4. Then go to Customize, the Skills tab, click + Add, choose Upload skill, and pick the .zip again.
I unzipped a Claude file by accident.

No problem. Download the pack again (see "I can't find my download" below) and upload the .zip files straight from the fresh download without opening them.

The assistant is uploaded but nothing happens.

Check that its toggle is switched on in the Skills tab. Then start a new chat and either type / and pick the assistant from the list, or just ask in your own words, like "How did my week go?"

How do I set them up in ChatGPT?

Open the .txt file for the assistant you want, copy everything below the line, paste it into a new ChatGPT chat, and send "Let's get started." This works on any plan. If your plan includes Projects, you can paste the instructions into a Project's instructions box so they're always ready. ChatGPT's menus change often, so if something looks different, search ChatGPT's help center for "Projects."

Do I need a paid Claude or ChatGPT plan?

No. Free plans work for trying the assistants. If you use them every day, a paid plan gives you more room. Calm Assistants don't include an AI subscription.

Using them

Day-to-day questions

It keeps asking me the setup questions again.

The first time, each assistant gives you a short profile. Save it. Paste it at the start of your next chat, or keep it in your Project or saved instructions, and you'll only answer the questions once.

The answer is too long or too formal.

Just tell it: "Shorter and warmer, please." You can also open the instructions (they're written in plain English) and change the tone or format to fit you.

It got a detail wrong or made something up.

Point it out and ask it to use a blank instead, like [your cancellation policy]. Then update your saved profile so it has the right details next time. If it keeps happening, email us so we can improve the assistant.

Will it send emails or post anything on its own?

No. Every Calm Assistant only reads, sorts, summarizes, and drafts. Drafts are labeled for you to review, and you send them yourself.

Is my business information private?

The assistants run inside your own Claude or ChatGPT account, so your emails, clients, and numbers stay there. We never see them. Your AI provider's own privacy settings apply.

Can it give me tax, legal, or financial advice?

No. The assistants point out what your numbers show and suggest checking with a professional you trust when it matters.
